# HW-43-TypeScript

GoIT TypeScript homework covering promises, utility types, generic functions and generic classes.

## Exercises

1. Type a Promise resolving to an array of strings and numbers.
2. Use Pick to type the arguments of compare().
3. Add generic types to merge().
4. Fix Component and Page using generics and an interface.

## Run

Install dependencies:

    npm install

Compile TypeScript:

    npm run build

Start watch mode:

    npm run watch

Open index.html using Live Server.

## Deployment

The compiled static website can be published with GitHub Pages.
