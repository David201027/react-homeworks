# HW-41-TypeScript

GoIT TypeScript fundamentals homework.

## Task 1

The file `src/index.ts` contains solutions for primitive types, any, unknown, readonly tuples, enums, unions, literal types, function typing, and custom object types.

## Task 2

Initialize TypeScript:

```bash
npx tsc --init
```

Compile:

```bash
npm run build
```

Watch mode:

```bash
npm run watch
```

Change `target` in `tsconfig.json` between `ES5` and `ES6` and compare the generated JavaScript.

Use VS Code Run and Debug with the provided launch configuration.

## Deployment

The root `index.html`, `styles.css`, and generated `dist/index.js` form a static website.
